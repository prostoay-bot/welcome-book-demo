# Welcome Book — демоверсия

Интерактивный HTML-гид для новых сотрудников на примере вымышленной компании «Ромашка».

Открыть локально: скачайте `index.html` и откройте его в браузере.

Публикация: GitHub Settings → Pages → Deploy from a branch → main → / (root).

Демонстрационные имена, контакты, рабочие условия, фотографии и поля «Указать…» необходимо заменить перед использованием в реальной компании. Для внешних фотографий и шрифтов требуется интернет.
